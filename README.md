# Анализ строительной отчётности и задач

Учебный проект по изучению данных полевого приложения для управления строительными проектами и разработке аналитических дашбордов в Yandex DataLens.

## Контекст кейса

В рамках задания требовалось подготовить дашборд для менеджеров строительного проекта, который позволяет оценивать работу команды, состояние отчётности и выполнение связанных действий и задач.

Исходный датасет состоял из двух CSV-файлов:

- `Construction_Data_PM_Forms_All_Projects.csv` — отчёты по проектам, содержащие сведения о прогрессе, состоянии отчётности и командах;
- `Construction_Data_PM_Tasks_All_Projects.csv` — действия и задачи, выполняемые в ходе проектов.

Обе таблицы были представлены на английском языке и содержали большое количество записей. На начальном этапе структура данных и назначение отдельных полей не были очевидны, поэтому сначала потребовалось разобраться в предметной области, перевести основные термины и определить взаимосвязи между таблицами.

## Задача проекта

Изучить и подготовить исходные данные, определить информативные показатели и разработать в Yandex DataLens дашборды, которые позволяют:

- оценивать общее состояние карточек отчётности;
- сравнивать открытые и закрытые записи;
- анализировать распределение данных по группам;
- отслеживать изменение количества карточек во времени;
- сравнивать количество действий и задач между группами;
- выявлять открытые и просроченные задачи;
- определять направления, требующие дополнительного внимания со стороны менеджеров.

## Этапы выполнения

Работа над проектом включала следующие этапы:

1. Изучение структуры и содержания исходных таблиц.
2. Перевод и интерпретация основных терминов и значений.
3. Очистка данных в Excel: удаление ненужных столбцов, проверка записей и подготовка таблиц к дальнейшему анализу.
4. Подключение подготовленных данных к Yandex DataLens и настройка датасетов.
5. Определение показателей и подготовка аналитических визуализаций.
6. Разработка двух дашбордов с фильтрами и дополнительными индикаторами.
7. Проверка отображения данных без фильтров и при выборе отдельных значений.

## Результат

В результате были разработаны два дашборда:

### 1. «Карточки отчётности»

Дашборд предназначен для анализа состояния карточек отчётности. Он включает визуализации, позволяющие:

- сравнивать открытые и закрытые карточки;
- анализировать распределение карточек по группам;
- отслеживать изменение количества карточек во времени;
- оценивать состояние связанных действий.

На дашборде предусмотрена фильтрация по группам принадлежности. При выборе одной или нескольких групп показатели и графики пересчитываются с учётом выбранных значений.

### 2. «Анализ распределения задач»

Дашборд предназначен для анализа задач и связанных с ними признаков. Он позволяет:

- сравнивать количество задач между группами;
- анализировать распределение задач по статусам;
- оценивать соотношение задач разных типов;
- выявлять задачи с признаками просрочки;
- рассматривать показатели отдельно для выбранного статуса отчёта.

Для второго дашборда предусмотрена фильтрация по статусу отчёта.

Всего в проекте использовано шесть графиков: четыре на первом дашборде и два на втором. Для демонстрации работы фильтров подготовлены варианты отображения без фильтрации и с выбранными значениями в селекторах.

## Ограничения интерпретации

Проект выполнен в рамках учебного задания. Представленные показатели характеризуют данные, содержащиеся в исходном датасете, но не позволяют самостоятельно оценить строительный проект в целом.

Например, доля закрытых карточек не является прямым показателем успешности проекта, поскольку для полноценной оценки также потребовались бы сведения о сроках, бюджете, критичности проблем и фактическом выполнении работ.

Причины изменения показателей во времени также не всегда можно определить только по представленным данным. Поэтому возможные объяснения выявленных тенденций требуют дополнительной проверки.

## Инструменты

- **Excel** — изучение структуры, перевод, очистка и предварительная подготовка исходных данных.
- **Yandex DataLens** — подключение данных, настройка датасетов, создание графиков, фильтров и дашбордов.
